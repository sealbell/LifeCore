# LifeCore v0.1 预览使用说明

版本：`0.1.0-alpha.1`。宿主选择已确定为 **DSH**，普通 QQ 接入选择 **SnowLuma**。这是可运行的首个预览，不代表完整 G1 或 G0–G6 已验收。

## 先看效果

在项目目录运行以下 PowerShell 命令。脚本使用 DSH 自带 Node，创建独立的 `lifecore-preview` 配置并安装本项目，保留原来的 `desktop` 配置。

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/start-preview.ps1
```

浏览器打开 DSH 后，进入 **左下角账号菜单 → 设置 → 生命核心**。已完成本机浏览器授权时，也可访问 `http://127.0.0.1:4317/lifecore/`。首次出现的 DSH 欢迎引导可选择“添加 API Key → 稍后配置”；要进行真实试聊，需要在 DSH 的模型设置中配置可用模型。

1. 在“出生与试聊”填写名字和自然语言设定，保存草案。
2. 在“连接与组件”填写 DSH 的 Provider ID、Model ID，保存配置。凭据仍由 DSH 管理。
3. 回到出生页试聊。草案每次保存会切换到新的隔离试聊上下文。
4. 满意后由你点击“确认正式诞生”。此后本地聊天进入正式经历，身份在重启后保留。

不要把自动化测试中的临时身份当成正式生命。启动器不会自动创建生命、选择收费模型、登录 QQ 或发送消息。

## 从安装包接入 DSH

源码开发需要 Node >=22.16、Python >=3.12，运行 `npm ci` 安装锁定依赖。本机 DSH 自带 Node 24.21 与 Python 3.12，启动器会优先复用。

```powershell
# 新建专用配置。只在该配置尚不存在时执行第一行，避免重置已有配置。
dsh lifecore-preview --from-default-profile web --dump-config > $null
dsh plugin --profile lifecore-preview add ./lifecore-dsh-0.1.0-alpha.1.tgz
dsh lifecore-preview --port 4317
```

`plugin add` 会登记插件的 bundle 与管理页入口，无需再额外传 `--patch`。不要同时用两个宿主进程打开同一个生命数据目录。桌面原有配置由 DSH 管理，本说明采用单独的 Web 配置进行安装。

只看界面也可以 `npm run dev`，访问相同地址；此模式的数据目录为 `~/.lifecore/preview`，**没有 DSH 模型服务，不会产生模拟回复**。它不能与占用 4317 的 DSH 预览同时启动。

安装视频浏览器：在已安装 LifeCore 依赖的目录运行 `npx --no-install playwright install chromium`。没有浏览器时，出生与 QQ 功能仍可用。不要把固定版本解释为已验证所有网站兼容性；升级时需要重新跑验收。

“复制组件安装任务”按钮生成给 DSH 的明确安装任务；当前尚未实现自动唤起宿主执行安装。安装任务要求先核对发布来源、版本和目标目录，并保留用户自行登录账号的步骤。

## 普通 QQ

在 SnowLuma 中启用 **OneBot 11 正向 WebSocket**，只监听本机，设置访问令牌。LifeCore 组件页填写：网关地址、SnowLuma 登录的 QQ 号、允许互动的 QQ 私聊白名单、令牌。保存后点击连接；插件会调用 `get_login_info` 与 `get_status` 核对账号及在线状态。

当前仅处理白名单的**纯文本私聊**，不处理群聊、图片、语音、临时消息工作流、头像或空间操作。需要正式诞生、模型配置完整且活动未暂停才会回复。令牌仅保留在宿主内存，重启后需重新填写并连接。

发送得到 `message_id` 才记为成功；超时或连接中断记为“结果未知”，不会自动重发。实际平台成功不等于对方已读。已用本机协议测试服务器验证握手、账号不符、重复事件及回执状态，**尚未使用真实 QQ 账号收发验收**。

## 视频活动

接受 B站或抖音 HTTPS 地址，打开独立浏览器配置，不复用日常浏览器的 Cookie。可以读取视频标题、播放位置、暂停和恢复；对话打断时先暂停，最后一个回合结束后尝试续播。主动暂停、换视频或配置失效会阻止旧回合自动续播。

重启后需要重新打开原视频，同一个视频会尝试恢复保存位置；无法找到播放器、登录限制、浏览器自动播放限制等均会显示失败。**只读取标题与播放器状态，尚未理解字幕、音频或画面，也没有自主推荐/刷视频调度。** 本地真实播放器验收不等于 B站/抖音真实网站验收。

## 数据、停止与备份

正式数据默认在 `~/.lifecore/v0.1`；`LIFECORE_DATA_DIR` 可显式更改。SQLite 内核采用单写者锁、事务与 WAL。数据库故障不会自动创建替代身份。暂停使尚未提交的回合失效；已经发给网关的请求无法撤回，仍会记录后续回执。

JSON 导出包含正式身份、事件、动作与活动，不包含试聊、模型密钥或 QQ 令牌。此导出用于审阅，**当前没有 JSON 导入恢复功能**。完整备份请先停止宿主，再复制整个数据目录；恢复时停止宿主并使用同一版本。卸载代码不会删除独立数据目录。

在启动终端按 Ctrl+C 停止。DSH 生命周期会停止工作内核；父进程退出时 Python 也会因管道关闭而退出。

## 开发验收

```text
npm test             # Python + Node：身份、隔离、取消、协议与生命周期
npm run test:ui      # 临时数据：草案、诞生、刷新、缺模型提示、桌面/窄屏
npm run test:browser # 本地真实播放器：打断、暂停、同视频恢复
npm run verify:host  # Windows DSH 隔离配置：安装、认证、设置页和内核
npm run doctor      # 只检查运行环境，不启动 QQ
npm pack            # 生成可安装 tgz
```

自动化使用临时数据库和合成账号，不发送真实 QQ 消息、不请求收费模型。尚未实现完整 SeekMemory/四层记忆、人格演化、后台星图、群聊、多平台和自主生活；当前对话仅使用本场景最多 16 条且有字符上限的近期经历。
