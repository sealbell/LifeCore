# M01 出生、试聊与初始状态确认

日期：2026-10-29

状态：产品流程及试聊时草案与对话并排的布局已由维护者确认；其余 Web UI 细节、接口与数据结构仍待详细设计。本文是讨论决策记录，不是实施计划；尚无产品实现。

关联：[架构 V1](../v1.md) · [讨论登记](../discussions.md)

## 1 已确认的流程

自然语言设定 → 档案草案 → 反复试聊与修改 → 选择初始记忆 → 可选确认关系状态 → 最终确认 → 正式出生。

正式出生前可以保存草案并继续编辑；确认成功后生成唯一生命身份。重启、插件重载、换模型或恢复已有档案均延续同一生命，不重新出生。读取异常进入诊断与恢复流程，不能当作首次使用。

## 2 档案内容与来源

- 用户自由描述出生设定和初始人格；原稿保留。
- 系统先提出补充建议。草案区分用户明确设定、对原文的整理解释、系统新增建议，并能追溯对应来源。
- 用户可以改写、接受、删除或暂缓建议；未确认的补充不能进入正式出生档案。
- 接受建议不抹去其最初来源；后续人工修改保留修订记录。
- 最终保存的是用户看到并确认的版本，不在确认后再次调用模型生成替代档案。

## 3 两个预设人格

维护者确认：参考 qq-bridge 的人格配置体验，提供两个预设人格，让用户先试用，也允许从空白自然语言设定开始。

预设是出生草案的起点，不是两个同时运行的正式生命；选择预设不自动出生，正式出生后不以切换模板重置身份。预设内容的来源应标为预设模板，不能冒充用户原文。

两个预设的名称、性格、文案及素材来源尚未确认。讨论草图中的预设仅为示例，不代表已批准正式内容；不默认复制 qq-bridge 的角色文本。qq-bridge 的 `qq-chat` / `qq-chat-v2` 是宿主聊天预设，不能直接当成这里的两个人格。

## 4 试聊隔离

- 用户可连续试聊几轮，检查人格表现；不满意就修改草案，再继续或新开一段试聊。
- 当前试聊有自己的上下文；旧试聊可供比较，不自动变成正式经历。
- 试聊产生的记忆、熟悉感、关系、情绪和人格变化不整体自动继承。
- 正式人格来自最终确认的档案；试聊表现不能偷偷写回人格草案或正式人格。

## 5 可选择的初始记忆与关系

用户先选中试聊内容，系统整理为可编辑的记忆草案，再由用户确认。默认仅导入选中并确认的记忆，未选中的试聊不参与正式互动。

关系导入默认关闭。用户可另外选择带入熟悉感和关系状态；状态、依据分别展示，允许修改并单独确认。关系维度沿用 M06 的熟悉、信任、亲近和边界方向，具体字段及数值尺度未冻结。

修改人格后，原待导入关系必须保留供复核。系统可提出调整建议，逐项标出原状态、建议状态、变化及理由，不直接覆盖；允许用户保留原值、接受或改写。人格变动不必然意味着关系改变。受影响的已确认内容标记待复核。

选中的记忆和关系作为“出生时由用户确认的初始记忆／关系”保存，保留试聊来源；不伪装为正式出生后发生的经历，不自动累计自然成长证据。

## 6 正式出生

最终确认的内容包括身份和人格档案、选中并确认的初始记忆，以及额外开启并确认的关系状态。出生时间以正式保存成功为准。

出生提交需要整体成功；重复点击、刷新或重试不能产生第二个生命。保存失败不能显示出生成功；保存成功但页面未收到结果时，应读取既有结果恢复显示。具体事务和幂等接口由 M02/M13 详细设计落实。

正式出生档案和当前成长状态分别保留。出生后的人工调整是管理修订，不伪装为自然成长。

## 7 对相关模块的约束

| 模块 | 需要遵守的约束 |
| --- | --- |
| M02/M13 | 草案版本、试聊与正式生命隔离；确认版本校验；出生整体提交、幂等和恢复 |
| M03/M04 | 初始记忆保留试聊来源，不能自动重放为正式事件或重复成长证据 |
| M06 | 关系导入独立选择与确认；新建议不覆盖旧状态 |
| M07 | 未选中的试聊及自生成解释不贡献正式成长；人格以确认档案为准 |
| M12 | 试聊和导入材料保持来源隐私限制；导入不意味着公开分享 |
| M14/M15 | 出生配置、试聊、内容复核与确认入口；宿主管理页接入仍需验证 |

## 8 后续验收场景

1. 用户删掉补充建议后出生，该建议不出现在正式档案。
2. 试聊后不选择任何内容出生，正式记忆与关系不包含试聊生成内容。
3. 只选记忆且未开启关系导入，正式记忆包含选中项，关系不继承试聊变化。
4. 开启关系导入并改写一项，正式状态与用户确认值一致。
5. 修改人格后，原关系仍可查看；建议差异与理由可见，未确认建议不会生效。
6. 最终确认后不再次生成档案；重复确认、断开或重启后仍是同一个生命。
7. 两个预设分别可供试用；未确认时不产生正式生命，正式出生后不提供模板切换来重置身份。
